description: Mejoras de calidad a escala SERIE que el usuario pidio recordar para mas adelante (no implementar sin ok).

El usuario (2026-07-18) aprobo implementar el Lector de Saga y la revision de costuras entre volumenes, y pidio RECORDAR estas dos para un futuro:

1. **Repeticion semantica ENTRE volumenes**: el detector semantico corre solo dentro de cada volumen; metaforas fetiche, escenas calcadas y set-pieces repetidos entre tomos pasan sin detectar. Extenderlo a escala serie comparando resumenes/muestras por tomo (no releer todo).
2. **Deriva de voz entre tomos**: volumenes generados en momentos distintos pueden derivar en registro, ritmo de frase o densidad descriptiva. Auditor que compare muestras de prosa de cada volumen y señale derivas.

**How to apply:** cuando el usuario pida "mas mejoras de calidad de series" o similares, ofrecer estas primero recordando que quedaron pendientes.
